# brain-tumor-radiomics-xgboost-lightgbm-catboost
Benchmarked XGBoost, LightGBM, and CatBoost on 3,762 brain tumor radiomics samples with extensive performance comparison
## Dataset
The dataset used in this project is taken from Kaggle:
[Brain Tumor Dataset on Kaggle](https://www.kaggle.com/datasets/jakeshbohaju/brain-tumor)
